# 日本への旅 · Japanese Learning Journey

An iPad-first, bilingual (Spanish / English) Japanese-learning pilot. Sakura Manga Passport visual direction.

## Pilot content

- L01: Greetings and courtesy
- L02: Introducing yourself
- L03: Asking for help
- Explanations and common misconceptions in both languages.
- Interactive recognition and short free-text retrieval exercises.
- In-session review, elapsed **active visible-tab time**, and JSON Learning Report export.
- Copyable ChatGPT Live practice script for each lesson.

## Privacy and limitations

- Public static site; **do not enter confidential information**.
- Responses are held in tab memory only, not sent to a backend. Language preference alone is stored locally.
- Download reports **before closing or reloading**; there is a warning on attempted exit.
- Reports may contain a voluntarily entered first name or alias; only upload/share them intentionally.
- A single correct answer does not demonstrate retained mastery or speaking ability.
- The device's Japanese speech synthesis is a **provisional, unvalidated** listening aid. It is **not** an authoritative pronunciation model. Reviewed native audio should replace it.
- Voice conversations in ChatGPT are not automatically imported into reports.
- Weekly aggregates should be calculated from multiple report files in the private Google Drive tracker, with de-duplication by `sessionId`.
- This is the first three-lesson prototype, not the complete curriculum.

## GitHub Pages

Publish the repository's `main` branch at `/ (root)` under **Settings → Pages → Build and deployment**. No build step is required.

## Learning report format

`japanese-learning-journey/report-v1` includes a session ID, timestamps, active seconds, attempts and skills. Never commit student reports or private trackers to this public repository.
